# Ana Paula Vargas Torres — Portfolio

Personal portfolio of **Ana Paula Vargas Torres**, Designer & Visual Communicator (Internal Communication @ AstraZeneca, Guadalajara) and Industrial Design student at Tecnológico de Monterrey.

Two design versions live side by side — open `index.html` for the main one.

## Versions

| Version | Folder | Style |
|---|---|---|
| **v1 (main)** | `index.html` | Electric blue + sky, Apple Store-inspired, gradients, autoplay project carousel, lightbox |
| **v2** | `v2-frameblox/` | Frameblox-inspired: navy + orange cards, coverflow carousel with theme filters |

## Sections (v1)

- Hero with profile photo, role pills and stats
- Work carousel — 4 Behance case studies + Bosch conceptual poster (Figma), autoplay, dots, thumbnails, lightbox
- About, Experience timeline (AstraZeneca · PrepaTec · TMF Group · Education)
- Courses & Certifications (66 hrs of online specializations + diploma + TOEFL)
- Skills, Contact (mailto form, no backend)

## View locally

Just open `index.html` in a browser — no build step, no dependencies. Or serve it:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Push this folder to a repo (e.g. `anapauvargas/portfolio`).
2. Repo → **Settings → Pages** → Deploy from branch → `main` / root.
3. Your site will be live at `https://<user>.github.io/<repo>/`.

## Customize

- **Profile photo:** replace `IMG_1234.JPG` (same filename, any portrait).
- **Bosch poster:** export it from Figma as `bosch-poster.jpg` next to `index.html`, then swap the gradient cover (marked with a `TODO` comment in `index.html`).
- **Contact email:** search `apvarto@gmail.com` in `index.html` / `script.js`.
- **LinkedIn:** `https://www.linkedin.com/in/anapaulavargas4` (already linked in About, Contact and footer).
- **Courses:** edit the `#courses` cards in `index.html`.
